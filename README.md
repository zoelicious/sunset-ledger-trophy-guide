A complete, spoiler-safe trophy guide and progress tracker for **Grand Theft Auto VI** — all 55 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze), with own-words guides, linked sources, a points-of-no-return / Missables tab, a 10-stage roadmap, and PSN-points + export tracking.

Built for the [gta6-trophy-guide-01 bounty on make.fun](https://make.fun/bounty/gta6-trophy-guide-01).

## What is inside

- **Progress dashboard** — big X/55 ring, per-grade breakdown, PSN points (X/1,230), earned by grade and by kind.
- **Trophy cards per category** — grade badges, “Hidden on PSN” markers, MISSABLE / time-sensitive flags, spoiler mode, filters and search.
- **Missables tab** — the 3 points of no return (1 missable + 2 time-sensitive), each with sources retrieved 2026-11-19.
- **Roadmap tab** — vertical 8-phase timeline plus a 10-stage mini-grid, with per-stage progress.
- **Detail panel** — counter stepper, roadmap stage / chapter box, WHERE/HOW boxes, and ≥3 linked sources per trophy.
- **Progress & export tab** — PSN points, earned-by-grade/kind bars, roadmap stages, and last-export metadata.

## Run it

```sh
node main.ts
```

Then open the local server (default port 8080). No build step, no third-party dependencies beyond the vendored files.
